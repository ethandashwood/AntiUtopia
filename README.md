# Ant-Utopia

**A 3D first-person shooter that adapts to how you play.**

Ant-Utopia is a 3D FPS built in Unity and C#. Its adaptive difficulty system tracks how you're doing and adjusts the challenge as you play. New players get room to learn, and skilled players are kept under pressure.

---

## Features

- **Adaptive difficulty:** the game reads your performance and scales the challenge to match your skill.
- **First-person shooting:** fast, responsive FPS gameplay in a fully 3D world.
- **Pick up and play:** familiar controls, so you can start right away.

## Controls

| Action | Input |
|---|---|
| Move | `W` `A` `S` `D` |
| Aim | Mouse |
| Shoot | Left click |

## How to Play

1. Download or clone this repository.
2. Open the game folder.
3. Run **Ant-Utopia** to start the game.

```bash
git clone https://github.com/ethandashwood/AntiUtopia
```

## Built With

- [Unity](https://unity.com/): game engine
- C#: gameplay and adaptive difficulty logic
